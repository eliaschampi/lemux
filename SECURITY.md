# Security policy

lemux runs commands with root rights and deletes files, so security reports matter.

Please **do not open a public issue** for a vulnerability. Report it privately through
GitHub: *Security → Report a vulnerability* on this repository. Include the lemux
version (`lemux --version`), your distribution and the steps to reproduce.

You will get an answer within a week. Fixes are released as a patch version and
credited in the changelog unless you prefer otherwise.
